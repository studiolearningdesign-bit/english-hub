# FASE 0 — REGLA GENERAL DE LA MARCA

Antes de tocar Facebook, conserva estas reglas durante TODO el proceso.

Learning & Development Studio no debe presentarse como:

- una página de clases particulares;
- una escuela infantil;
- un centro de tareas;
- una página de descuentos;
- una academia genérica de inglés.

Debe sentirse como un **estudio profesional especializado en aprendizaje y desarrollo**.

La percepción visual debe ser:

**Premium · Professional · Contemporary · Personalised · Educational**

Nunca utilizaremos:

- explosiones de colores;
- rojo promocional;
- amarillo de oferta;
- banderas de Estados Unidos o Reino Unido como recurso principal;
- clipart;
- birretes genéricos;
- pizarrones;
- dibujos infantiles;
- demasiados emojis;
- “¡APRENDE INGLÉS YA!”;
- “OFERTÓN”;
- precios enormes;
- diez servicios dentro del mismo flyer.
